# deslop

あらゆる言語の文章から、AIっぽい定型パターン（通称"slop"）を検出して取り除くClaudeスキル。人が意図をもって書いたように読める文章にする。

English version: [README.md](README.md)

## 何をするか

AIが書いた文章は、特徴的な癖に収束する。何を書くかを述べる前にそれを予告するメタ発言、手垢のついた比喩、機械的な「AではなくB」構文、ヘッジの連なり、単調なリズム。こうした失敗のパターンは言語を超えて共通で、表層の形だけが違う。`deslop` は言語に依らない検出・書き換えのプロセスを一本用意し、現時点では英語と日本語の専用カタログで裏づける（それ以外の言語は8つの普遍カテゴリを直接あてはめる）。

動作は2モード。

- **検出＆修正**（既定）— 検出箇所をカテゴリ別に列挙し、slop率を測り、保護すべき表現のリストを作った上で**削除 > 圧縮 > 置換** の優先順で書き換え、再測定・五次元セルフスコアを行い、before/afterの変更点を報告する。
- **検出のみ** — スコアだけ知りたいとき（「slop率は？」）は、測定結果を報告して止まる。

ユーザーが頼まなくても動く場面もある。Claude自身が書いた長文の文書は納品前に自動でセルフチェックし、日本語での会話応答にも軽量版のチェックをかける。

## slop率

```
slop率 = 検出パターンを1つ以上含む文 / 総文数 × 100 (%)
```

| slop率 | 判定 |
| ------ | ---- |
| < 10%  | Low — 人が書いたように読める。部分修正のみ |
| 10–25% | Moderate — AIっぽさが目立つ。狙い撃ちで書き換え |
| 25–50% | High — 明らかにAI調。全面的に書き換え |
| > 50%  | Severe — 全体が定型。論旨から組み直しを検討 |

これは有限のカタログに対するLLMの判断であって、決定論的な検出器ではない。同じテキストの before/after を比較できる程度には再現性があるが、AIが書いたかどうかを証明するものではない。人が書いても高く出ることがあるし、手を入れたAI文章が低く出ることもある。

## 8つの普遍的slopカテゴリ

1. **記号・約物の癖** — 多用されるダッシュ、スケアクオート、装飾的な太字、絵文字の飾り。
2. **メタ発言・自己実況** — 「重要なのは」「結論として」、修辞疑問への自問自答。
3. **紋切り型・死んだ比喩** — 「ゲームチェンジャー」、「地図/時代/波」の比喩、作り物の名言風フレーズ。
4. **構造テンプレート** — 第一に/第二に、三点セット反射、否定の列挙、全体を要約する締め。
5. **偽の主体・主語なき語り** — データが「語る」、文化が「変わる」、宙に浮いた講釈口調。
6. **リズムの単調さ** — どの文も同じ長さ・同じ語尾（〜ますの連鎖など。逆に短文の畳みかけも同罪）。
7. **ヘッジと偽の中立** — 「かもしれない」の連続で全主張を薄める。逆に「常に/決して」の安易な極論も。
8. **内容の希薄化** — 同じことの言い換え、平凡な着地、「示唆は大きい」式の曖昧な断言。

`deslop` は絶対禁止ではなく**頻度ベース**の立場をとる。印象的な表現も一度なら文体、同じ手垢の表現が毎回出れば slop。独自の比喩、意図的な反復、書き手の文体（語調・漢字/かなの選択）は保つ。deslopが変えるのは文体であって、論旨ではない。

## ファイル構成

- `SKILL.md` — スキル定義（ワークフロー、測定、カテゴリ、検証）。
- `references/english.md` — 英語のパターンカタログ。
- `references/japanese.md` — 日本語のパターンカタログ（翻訳調、過剰な接続語、定型の相槌、終助詞の過不足ほか）。

専用カタログが無い言語は、8つの普遍カテゴリを直接あてはめて扱う。

## 使い方

Claudeスキルとして導入すれば、AIっぽさの除去・文章の自然化・校正・slop採点を頼むだけで起動する。言語は問わない（「自然な文章に」「slop率を出して」「make this sound less AI」）。加えて、Claudeが自分で書いた長文文書の納品前や、日本語での会話応答でも、頼まれなくても自動で軽量なセルフチェックが働く。

## 謝辞

カテゴリの枠組みは [stop-slop](https://github.com/hardikpandya/stop-slop)（MIT）の発想を拡張したもの。とくに偽の主体、否定の列挙、遠くからの語り手、名言風フレーズ(pull-quote)の各概念と、5次元のスコアリング指標を借りている。これらを多言語へ一般化し、絶対禁止を頻度ベースの判断に置き換えた。
